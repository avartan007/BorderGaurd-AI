# BorderGuard AI — runtime dependencies.
#
# Why these exact pins
# --------------------
# Streamlit Community Cloud provisions Python 3.14 (its build log reported
# "Using Python 3.14.8"). The previous pin, torch==2.6.0 + torchvision==0.21.0,
# is unsupported there and the install failed with:
#
#   Because torch{sys_platform == 'linux'}==2.6.0+cpu has no wheels with a
#   matching Python ABI tag ... your requirements are unsatisfiable.
#
# PyTorch's own matrix caps that pair at Python <=3.12, and no cp314 wheels were
# ever published for it. torch 2.10 / torchvision 0.25 is the oldest pair that
# officially supports Python 3.14 (matrix says >=3.10,<=3.14) and ships cp314 CPU
# wheels. torchvision pins its exact torch version, so these two move together.
#
# Verified on Python 3.14.8 (the version Cloud reported) and independently on
# 3.13.5, so the pins hold across the 3.13-3.14 range rather than only on 3.14.
#
# The +cpu suffix only exists on PyTorch's CPU index, hence --extra-index-url.
# PyPI's default Linux wheels carry the ~2.5 GB CUDA stack; the CPU index keeps
# the install to ~200 MB. macOS ships no +cpu wheels at all, and its normal PyPI
# wheels are already CPU-only, so darwin gets the plain (no-suffix) versions.
--extra-index-url https://download.pytorch.org/whl/cpu

torch==2.10.0+cpu; sys_platform == "linux"
torchvision==0.25.0+cpu; sys_platform == "linux"

torch==2.10.0; sys_platform == "darwin"
torchvision==0.25.0; sys_platform == "darwin"
